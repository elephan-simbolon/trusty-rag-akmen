## Integration Findings

### Critical Issues

#### 1. Conversation Memory Non-Functional (UI-02, RETR-06)

**Severity:** Major
**Location:** `frontend/src/hooks/useStreamingQuery.ts` line 39
**Issue:** `session_id: null` hardcoded. Backend generates fresh UUID per query → MemorySaver checkpoint keyed to UUID never reused → multi-turn conversation memory broken.
**Fix:** Generate stable UUID per browser session (`const sessionId = useRef(crypto.randomUUID()).current`) and send as `session_id`.

#### 2. Langfuse Session Attribution Missing (MON-01, MON-03)

**Severity:** Minor
**Location:** `src/monitoring/langfuse_client.py` line 48
**Issue:** `CallbackHandler()` called without `session_id` or `user_id` arguments. These are accepted by `get_langfuse_handler()` signature but silently dropped.
**Fix:** `return CallbackHandler(session_id=session_id, user_id=user_id)`

#### 3. Dead QueryRequest Field (UI-02)

**Severity:** Minor
**Location:** `backend/models.py` line 9, `backend/main.py:query_sse`
**Issue:** `history_id` accepted in request body but never read. If intent is session restoration, thread_id lookup is missing.
**Fix:** Map `history_id` → `thread_id` for context restoration, or remove field.
