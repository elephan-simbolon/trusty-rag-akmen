<objective>
Close three v1.0 milestone audit gaps in a single cohesive plan:

- UI-02 (conversation memory): Frontend sends `session_id: null`, breaking LangGraph MemorySaver thread_id continuity across turns.
- MON-01/MON-03 (Langfuse session attribution): `get_langfuse_handler()` accepts `session_id`/`user_id` but silently drops them. Langfuse v4 requires `metadata` dict in `ainvoke` config, not constructor args.
- Dead API field: `QueryRequest.history_id` accepted by backend but never read — silent dead weight in the API contract.

**Langfuse v4 clarification:** ROADMAP success criterion #2 states "CallbackHandler receives session_id/user_id" — this describes the v3 API. Langfuse 4.0.1 `CallbackHandler.__init__` only accepts `public_key` and `trace_context`. The v4 equivalent is passing `metadata={"langfuse_session_id": ..., "langfuse_user_id": ...}` in `ainvoke` config. This plan implements the correct v4 mechanism, satisfying the intent of criterion #2.

**MON-03 clarification:** MON-03 performance threshold (≤10s Simple, ≤20s Complex) is already satisfied per v1.0 audit. The partial gap tracked here is trace session grouping — same root cause as MON-01.

Output: 5 modified files + 1 new test file. All changes are 1-5 lines each.
</objective>

        req = QueryRequest(question="test", session_id="abc-123")
        assert req.session_id == "abc-123"

        req = QueryRequest(question="test")
        assert req.session_id is None

        """get_langfuse_handler() must accept zero parameters (v4 API — no session_id/user_id)."""
        sig = inspect.signature(get_langfuse_handler)
        assert len(sig.parameters) == 0, (
            f"Expected 0 params, got {len(sig.parameters)}: {list(sig.parameters.keys())}"
        )


    @pytest.mark.asyncio
    async def test_query_sse_uses_session_id_as_thread_id():
        """Backend must wire session_id → config[configurable][thread_id] for MemorySaver."""
        from backend.main import query_sse

        mock_graph = MagicMock()

            async for _ in query_sse(request).__anext__.__self__ if False else []:
