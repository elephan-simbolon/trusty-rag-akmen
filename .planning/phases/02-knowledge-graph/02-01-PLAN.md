2. Create `src/knowledge_graph/graph_ingestion.py`:

   - Import: `asyncio`, `json`, `logging`, `Path` from `pathlib`; `build_lightrag_instance` from `src.knowledge_graph.lightrag_client`.

   - Define `logger = logging.getLogger(__name__)`

   - Define async function `ingest_chunks_to_lightrag(chunks_json_path: str, audit_mode: bool = True) -> dict`:
     Docstring: "Load Phase 1 chunks from JSON backup and insert into LightRAG. Returns dict with keys: total, ingested, failed."
     1. `rag = await build_lightrag_instance()`
     2. Load chunks: `chunks = json.loads(Path(chunks_json_path).read_text(encoding="utf-8"))`
     3. Log: `logger.info(f"Loaded {len(chunks)} chunks for LightRAG ingestion")`
     4. Select target: `target_chunks = chunks[:50] if audit_mode else chunks`
     5. Track counters: `ingested = 0`, `failed = 0`
     6. Loop over `enumerate(target_chunks)`:
        - Build `text_with_context` by prepending source metadata:
          ```python
          text_with_context = (
              f"[Source: {chunk['metadata']['book_title']}, "
              f"{chunk['metadata']['chapter']}, "
              f"page {chunk['metadata'].get('page_start', '?')}]\n\n"
              f"{chunk['text']}"
          )
          ```
        - `await rag.ainsert(text_with_context)` in try/except
        - On success: increment `ingested`
        - On exception: log error, increment `failed`, `continue` (do NOT re-raise — zombie task pollution per Pitfall 2)
        - Every 10 chunks: `logger.info(f"Ingested {i + 1}/{len(target_chunks)} chunks")`
     7. `await rag.finalize_storages()`
     8. Return `{"total": len(target_chunks), "ingested": ingested, "failed": failed}`
