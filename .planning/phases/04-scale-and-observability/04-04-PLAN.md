<objective>
Create a 20-query accounting evaluation set and an automated evaluation runner that scores retrieval citation relevance, enabling human review to verify >= 85% accuracy (MON-02).

Purpose: MON-02 requires measuring retrieval accuracy on a standardized set. Without this, accuracy claims are anecdotal. The evaluation set also serves as a regression test for future changes to retrieval, reranking, or the knowledge graph.

Output: `data/eval/eval_queries.json` (20 queries), `scripts/evaluate_retrieval.py` (runner), `tests/test_evaluation_set.py` (structure validation), and a human-verify checkpoint.
</objective>

2. Create scripts/evaluate_retrieval.py:
   ```python
   """Run 20-query evaluation set against the RAG system and score citation relevance.

   Usage:
       python scripts/evaluate_retrieval.py
       python scripts/evaluate_retrieval.py --output data/eval/results.json
       python scripts/evaluate_retrieval.py --dry-run  # just validate JSON structure
   """
   ```
   - Load eval_queries.json
   - For --dry-run mode: validate JSON structure (all 20 queries, required fields), print summary, exit
   - For full run: build Phase 3 graph, invoke each query, compare citations against expected_books
   - Score each query: PASS if at least one citation book_title matches any expected_book, FAIL otherwise
   - Output results JSON with per-query scores and overall accuracy percentage
   - Print summary: "Accuracy: {pass_count}/20 ({accuracy}%)"
   - Mark integration test with `if __name__ == "__main__"` guard
   - Add argparse with:
     - `--output` (default: data/eval/results.json)
     - `--dry-run` (validate structure only)
     - `--verbose` / `-v` (print per-query results)
