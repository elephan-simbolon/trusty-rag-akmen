<objective>
Add contextual window embedding as an API-compatible alternative to true late chunking (CHUNK-05). Each child chunk is embedded with its parent section text prepended, capturing cross-chunk semantics at ~15-25% additional token cost. Wire this into the ingestion pipeline so it is actually activated during ingestion.

Purpose: CHUNK-05 — true late chunking requires token-level pooling not available via SiliconFlow API. Contextual window embedding is the pragmatic API-compatible equivalent that improves retrieval by giving the embedding model section-level context for each chunk.

Output: `build_contextual_text()` function and `use_contextual_window` flag in `embed_chunks_batch()`, pipeline wiring that collects parent texts from hierarchy and passes them through, CLI `--contextual` flag, and unit tests.
</objective>

   ```python
   def build_contextual_text(
       chunk_text: str,
       parent_text: str,
       max_context_words: int = 256,
   ) -> str:
       """Prepend truncated parent-section context to child chunk text.

       API-compatible alternative to true late chunking (CHUNK-05).
       The embedding model sees the chunk text in the context of its
       surrounding section, improving cross-chunk semantic resolution.

       Args:
           chunk_text: The child chunk text to embed.
           parent_text: Parent section text for context. If empty, returns chunk_text unchanged.
           max_context_words: Maximum words from parent to include (default 256).

       Returns:
           Chunk text with context prefix, or unchanged chunk text if no parent.
       """
       if not parent_text or not parent_text.strip():
           return chunk_text
       words = parent_text.split()
       context = " ".join(words[:max_context_words])
       return f"[Context: {context}]\n\n{chunk_text}"
   ```

2. Modify embed_chunks_batch signature — add two new parameters:
   ```python
   def embed_chunks_batch(
       chunks: list[dict],
       batch_size: int = DEFAULT_BATCH_SIZE,
       checkpoint_path: str | None = None,
       use_contextual_window: bool = False,
       parent_texts: dict[str, str] | None = None,
   ) -> list[dict]:
   ```
   - `use_contextual_window`: When True, prepend parent context to each chunk before embedding
   - `parent_texts`: Dict mapping section_path -> parent section text. Used to look up context for each chunk. If a chunk's section_path is not found, embed without context.

3. Inside embed_chunks_batch, modify the text extraction in the batch loop. Replace:

   ```python
   if use_contextual_window and parent_texts:
       texts = []
       for c in batch:
           section_path = c.get("metadata", {}).get("section_path", "")
           parent = parent_texts.get(section_path, "")
           texts.append(build_contextual_text(c["text"], parent))
   else:
       texts = [c["text"] for c in batch]
   ```
   This is backward compatible — default behavior unchanged.
