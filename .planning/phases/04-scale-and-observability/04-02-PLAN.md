<objective>
Add incremental ingestion guard so new textbooks can be added to the corpus without re-processing existing books, and re-ingestion of the same book replaces (not duplicates) its chunks.

Purpose: INGEST-06 — enables scaling from 5 to 20-30 textbooks without full re-ingestion. Without this, every `ingest.py` run on the same book doubles the chunk count in Qdrant (Pitfall 3 from RESEARCH.md).

Output: `check_book_exists()` and `delete_book()` in qdrant_uploader, pipeline guard, CLI `--replace` flag, LightRAG book manifest, and unit tests.
</objective>

     def check_book_exists(client: QdrantClient, book_title: str, collection_name: str | None = None) -> bool:
         """Return True if any chunks for this book_title exist in Qdrant."""
         name = collection_name or settings.qdrant_collection_name
         results, _ = client.scroll(
             collection_name=name,
             scroll_filter=Filter(
                 must=[FieldCondition(key="book_title", match=MatchValue(value=book_title))]
             ),
             limit=1,
             with_payload=False,
             with_vectors=False,
         )
         return len(results) > 0
     ```

         name = collection_name or settings.qdrant_collection_name

     MANIFEST_PATH = Path(settings.lightrag_working_dir) / "ingested_books.json"

     def get_ingested_books() -> set:
         """Return set of book titles already ingested into LightRAG."""
         if MANIFEST_PATH.exists():
             return set(json.loads(MANIFEST_PATH.read_text()))
         return set()

         """Record a book title as ingested in the LightRAG manifest."""
         books = get_ingested_books()
         books.add(book_title)
         MANIFEST_PATH.parent.mkdir(parents=True, exist_ok=True)
         MANIFEST_PATH.write_text(json.dumps(sorted(books), ensure_ascii=False, indent=2))
     ```
