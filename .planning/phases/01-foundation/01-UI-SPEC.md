secondaryBackgroundColor = "#1E293B"
textColor = "#F1F5F9"

## Spacing Scale

Streamlit uses column widths and `gap` parameters rather than CSS pixel tokens directly.
The following logical scale maps Streamlit API parameters to the 8-point scale:

| Token | Value | Streamlit Mapping | Usage |
|-------|-------|-------------------|-------|
| xs | 4px | `st.columns([1, 20, 1])` side gutters | Icon gaps, inline metadata |
| sm | 8px | `st.markdown` default paragraph margin | Compact element spacing |
| md | 16px | `st.container()` padding default | Default element spacing |
| lg | 24px | `gap="medium"` in st.columns | Section padding |
| xl | 32px | `gap="large"` in st.columns | Layout gaps between chat and sidebar |
| 2xl | 48px | `st.divider()` + adjacent `st.write("")` | Major section breaks |
| 3xl | 64px | Top-of-page header spacing | Page-level spacing |

Exceptions:
- Chat input area: minimum touch/click height 44px (accessibility — source: WCAG 2.5.5 target size)
- Citation block `st.expander`: internal padding uses sm (8px) for compact source listing

## Typography

Streamlit renders markdown. All heading levels map to semantic HTML. Declare these exact mappings:

| Role | Streamlit Element | Rendered Size | Weight | Line Height | Usage |
|------|-------------------|---------------|--------|-------------|-------|
| Body | `st.write()` / `st.markdown()` | 16px | 400 (regular) | 1.5 | Response prose, descriptions |
| Label | `st.caption()` | 14px | 400 (regular) | 1.4 | Citation metadata, page numbers, timestamps |
| Heading | `st.subheader()` / `## markdown` | 20px | 600 (semibold) | 1.2 | Section titles ("Sumber Referensi"), chat session header |
| Display | `st.title()` / `# markdown` | 28px | 600 (semibold) | 1.1 | App title "Trusty RAG — Asisten Akuntansi" only |

Bilingual rule (source: LANG-03, REQUIREMENTS.md): All body text uses Indonesian prose. English
technical terms appear in parentheses with italic markdown:
`alokasi biaya overhead (*overhead cost allocation*)`

Exactly 2 weights are used across this entire spec: 400 (regular) for Body and Label, 600 (semibold)
for Heading and Display. The Display size of 28px provides sufficient visual hierarchy over the 20px
Heading without requiring a third weight.

## Color

Source: Streamlit config.toml values declared above.

| Role | Hex | Usage |
|------|-----|-------|
| Dominant (60%) | `#0F172A` | App background, chat message background (assistant) |
| Secondary (30%) | `#1E293B` | Sidebar, citation expander background, code blocks, user message bubbles |
| Accent (10%) | `#2563EB` | Primary CTA only (see reserved list below) |
| Destructive | `#DC2626` | Error state messages, parse failure alerts only |

Accent `#2563EB` reserved for:
1. The "Kirim Pertanyaan" submit button (primary CTA)
2. Active/selected state indicator on sidebar navigation (if sidebar is used)
3. Link text in citation blocks (book title as clickable reference)

Accent is NOT used for: response text, headings, metadata labels, dividers, icons, loading spinners.

Semantic color rules:
- Success state (ingestion complete): `#16A34A` (green) — used only in ingestion script CLI output, not in chat UI
- Warning state (VRAM limit approaching): `#D97706` (amber) — used only in admin sidebar, not visible to end user in Phase 1
- Destructive `#DC2626`: only for error messages where the user must take action (e.g., "Query gagal — coba lagi" with retry button)

## Component Inventory

These are the Streamlit components that must appear in Phase 1. The executor must use these
specific components — do not substitute.

| Component | Streamlit API | Purpose | State Handled |
|-----------|---------------|---------|---------------|
| Chat input | `st.chat_input("Ketik pertanyaan akuntansi...")` | User query entry | Disabled while response is streaming |
| Assistant message | `st.chat_message("assistant")` | Response display | Contains response prose + citation block |
| User message | `st.chat_message("user")` | User query display | Echoed immediately on submit |
| Citation block | `st.expander("Sumber Referensi (N buku)")` inside assistant message | Display citations | Collapsed by default in Phase 1 (UI-03 is Phase 5 — collapse is already correct behavior) |
| Loading spinner | `st.spinner("Mencari referensi...")` | Processing indicator | Active during retrieval + generation |
| Error alert | `st.error("...")` | Error display | Shown on retrieval failure or API error |
| Sidebar | `st.sidebar` | App info, ingestion status | `st.sidebar.collapsed = True` by default |
| Session state | `st.session_state.messages` | Chat history list | Persists within browser session; cleared on page refresh |

## Interaction States

Each interactive element must implement ALL states listed. No state may be left visually
indistinguishable from another.

### Chat Input Field

| State | Visual Treatment |
|-------|-----------------|
| Idle | Placeholder text visible: "Ketik pertanyaan akuntansi..." |
| Focused | Streamlit default focus ring (accent #2563EB border) |
| Submitted / loading | Input cleared; spinner shown above; input widget disabled via `st.session_state.processing = True` |
| Error | `st.error()` displayed above input; input re-enabled |

### Assistant Response Message

| State | Visual Treatment |
|-------|-----------------|
| Loading | `st.spinner("Mencari referensi...")` in assistant chat bubble placeholder |
| Streaming | `st.write_stream()` renders token-by-token if streaming; or full render on completion |
| Complete | Full prose visible; citation `st.expander` appended below prose |
| Error | Error message replaces prose; no citation block rendered |

### Citation Expander

| State | Visual Treatment |
|-------|-----------------|
| Collapsed (default) | Label: "Sumber Referensi (N sumber)" — N is the count of distinct citations |
| Expanded | Each citation on its own line in `st.caption()` style |
| No citations | Expander hidden entirely — do not render empty expander |

## Accessibility Notes

- All `st.chat_message` roles use semantic assistant/user roles — screen reader accessible
- Chat input minimum target size: 44px height (WCAG 2.5.5)
- Color contrast: `#F1F5F9` text on `#0F172A` background = 15.1:1 ratio (exceeds WCAG AA 4.5:1)
- `#F1F5F9` text on `#1E293B` secondary = 11.2:1 ratio (exceeds WCAG AA)
- Accent `#2563EB` on `#0F172A` background = 5.9:1 (passes WCAG AA for large text; use weight 600 for accent labels)
- Error `#DC2626` on `#0F172A` background: use `st.error()` which renders with white text on red — WCAG AA compliant
- Loading state: always provide `st.spinner()` text (not silent) — screen reader picks up spinner label
