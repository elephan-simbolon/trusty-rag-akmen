<objective>
Memperbaiki UI freeze yang dilaporkan pada UAT Test 11: tenacity retry config `_RETRY_CONFIG` (5 attempts x 60-300s backoff) memblokir seluruh UI thread Streamlit sebelum error handler sempat muncul.

Perbaikan: tambahkan `_UI_RETRY_CONFIG` dengan fast-fail (2 attempts, 2-10s backoff) dan terapkan pada `embed_query` dan `generate` — dua fungsi yang dipanggil dari Streamlit UI via LangGraph nodes. Fungsi batch ingestion (`embed_batch`, `embed_document`) tetap menggunakan `_RETRY_CONFIG` yang lambat karena SiliconFlow rate limiting nyata pada batch jobs.

Perbaikan ini tidak mengubah error handling di `app/main.py` (sudah benar) — hanya memperpendek waktu tunggu sebelum exception di-reraise ke handler tersebut.

Purpose: Setelah fix, user yang menjalankan UI tanpa `.env` dikonfigurasi akan melihat pesan error Indonesia dalam waktu kurang dari 30 detik, bukan setelah beberapa menit.

Output: `src/llm/client.py` dengan `_UI_RETRY_CONFIG`, satu test baru di `tests/test_embedding.py` yang memverifikasi konfigurasi retry.
</objective>
