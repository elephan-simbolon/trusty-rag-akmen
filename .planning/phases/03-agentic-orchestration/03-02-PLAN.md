1. **crag_grade_node** — reads `reranked_docs` from state, finds max `rerank_score`, grades:
   ```python
   def crag_grade_node(state: RAGState) -> dict:
       """Grade retrieval quality using reranker scores already in state.
       No additional LLM call — reranker is called exactly once in rerank_node.
       Thresholds: >=0.5 CORRECT, >=0.2 AMBIGUOUS, <0.2 INCORRECT.
       """
       reranked = state.get("reranked_docs") or []
       iterations = state.get("crag_iterations", 0)

       if not reranked:
           grade = "INCORRECT"
       else:
           max_score = max(doc.get("rerank_score", 0.0) for doc in reranked)
           if max_score >= 0.5:
               grade = "CORRECT"
           elif max_score >= 0.2:
               grade = "AMBIGUOUS"
           else:
               grade = "INCORRECT"

       return {"crag_grade": grade, "crag_iterations": iterations + 1}
   ```
   CRITICAL: Use `doc.get("rerank_score", 0.0)` — NOT `doc.get("score", 0.0)`.
   The RESEARCH.md example uses the wrong key ("score"). The reranker.py interface contract
   sets "rerank_score" on each document. This plan's version is correct.

2. **crag_router** — conditional edge function:
   ```python
   def crag_router(state: RAGState) -> str:
       """Route based on CRAG grade. Max 2 reformulation iterations."""
       grade = state.get("crag_grade", "CORRECT")
       iterations = state.get("crag_iterations", 0)
       query_type = state.get("query_type", "Simple")

       if grade == "CORRECT" or iterations >= 2:
           return "generate_calc" if query_type == "Calculation" else "generate"
       return "reformulate"
   ```

3. **reformulate_node** — uses LLM to create a reformulated query:
   ```python
   def reformulate_node(state: RAGState) -> dict:
       """Reformulate query when CRAG grade is AMBIGUOUS/INCORRECT.
       Writes to 'query' key so retrieve_node reads it on next loop iteration.
       This is 1 LLM call — accounted in budget.
       """
       original_query = state["query"]
       llm_count = state.get("llm_call_count", 0)

       reformulation_prompt = [
           {"role": "system", "content": "Kamu adalah asisten yang membantu mereformulasi pertanyaan akuntansi agar lebih spesifik dan mudah dicari di textbook. Tulis ulang pertanyaan berikut dengan kata kunci yang lebih tepat. Jawab HANYA dengan pertanyaan baru, tanpa penjelasan."},
           {"role": "user", "content": f"Pertanyaan awal: {original_query}\n\nTulis ulang pertanyaan ini agar lebih spesifik:"},
       ]

       try:
           reformulated = generate(reformulation_prompt, temperature=0.3)
           logger.info(f"Query reformulated: '{original_query}' -> '{reformulated}'")
           return {"query": reformulated.strip(), "llm_call_count": llm_count + 1}
       except Exception as e:
           logger.error(f"Reformulation failed: {e}, keeping original query")
           return {"query": original_query, "llm_call_count": llm_count}
   ```

4. **generate_calc_node** — Calculation-specific generation with disclaimer:

   ```python
   def generate_calc_node(state: RAGState) -> dict:
       """Generate calculation response using SYSTEM_PROMPT_GENERATOR_CALCULATION.
       Routes to calc-specific prompt that includes step-by-step instructions
       and mandatory disclaimer (GEN-02 + GEN-03).
       """
       if state.get("error"):
           return {
               "response": f"Terjadi kesalahan: {state['error']}",
               "citations": [],
           }

       docs = state.get("reranked_docs") or state.get("retrieved_docs") or []
       if not docs:
           return {
               "response": "Tidak ditemukan referensi relevan untuk pertanyaan ini di korpus textbook yang tersedia.",
               "citations": [],
           }

       graph_context = ""
       graph_docs = state.get("graph_docs") or []
       if graph_docs:
           graph_context = "\n\n".join(doc["text"] for doc in graph_docs if doc.get("text"))

       try:
           result = generate_response(
               query=state["query"],
               context_docs=docs,
               graph_context=graph_context,
               query_type="Calculation",
           )
           llm_count = state.get("llm_call_count", 0)
           return {
               "response": result["response"],
               "citations": result["citations"],
               "llm_call_count": llm_count + 1,
               "conversation_history": [
                   {"role": "user", "content": state["query"]},
                   {"role": "assistant", "content": result["response"]},
               ],
           }
       except Exception as e:
           logger.error(f"Calculation generation failed: {e}")
           return {
               "response": f"Gagal menghasilkan respons kalkulasi: {e}",
               "citations": [],
           }
   ```

2. Add a custom `before_sleep` callback that logs 429 specifically:
   ```python
   def _log_rate_limit(retry_state):
       """Log 429 rate limit events specifically for MON-05 monitoring."""
       exc = retry_state.outcome.exception()
       if isinstance(exc, httpx.HTTPStatusError) and exc.response.status_code == 429:
           logger.warning(
               "SiliconFlow rate limit (429) hit — retrying in %.1fs (attempt %d)",
               retry_state.next_action.sleep,
               retry_state.attempt_number,
           )
       else:
           before_sleep_log(logger, logging.WARNING)(retry_state)
   ```
