## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body / chat prose | 15px (0.95rem) | 400 (regular) | 1.75 | Inter |
| Label / badge / status | 12px (0.78rem) | 400 (regular) | 1.5 | Inter |
| Citation / mono | 13px (0.82rem) | 400 (regular) | 1.5 | JetBrains Mono |
| Heading / display | 24px (1.5rem) | 600 (semibold) | 1.2 | Playfair Display |

Weights in use: **400 (regular)** and **600 (semibold)** only.

**Note on 12px label vs 13px citation:** The 1px difference between label/badge (12px, Inter) and citation/mono (13px, JetBrains Mono) is intentional. JetBrains Mono has a narrower x-height-to-cap-height ratio than Inter at the same nominal size, causing it to read as visually smaller. The 13px value compensates for this monospace optical size reduction so that citation text reads at the same perceived size as label text. This is a monospace readability compensation, not a typographic inconsistency.

New Phase 3 elements follow these exact sizes:
- Query type badge (e.g., "Kalkulasi", "Sederhana"): 12px, weight 400, Inter — same as label row
- CRAG status indicator text: 12px, weight 400, Inter — same as label row
- Rate limit warning: 12px, weight 400, Inter — same as label row
- Conversation turn counter in sidebar: 12px, weight 400, Inter — same as `.stCaption`

## Visual Hierarchy

**Primary visual anchor:** The assistant's chat message bubble (`st.chat_message("assistant")`) is the focal point of every screen state — it is the largest, highest-contrast surface element and contains the query type badge, prose answer, and citation expander. All other elements (sidebar, spinner, warnings) are subordinate to it in size and color weight.

## Interaction States

All states required by Phase 3 requirements.

### Chat Input

| State | Visual Behavior |
|-------|----------------|
| Idle | `st.chat_input` enabled; placeholder "Ketik pertanyaan akuntansi..." |
| Processing (Simple/Medium/Complex) | Input disabled via `disabled=True`; spinner label "Mencari referensi..." |
| Processing (Calculation) | Input disabled; spinner label "Menghitung..." |
| CRAG reformulation loop (iter 1) | Spinner updates to "Mencari ulang referensi..." — one muted italic line above the spinner |
| CRAG max iterations hit, gap returned | Input re-enabled; assistant message shows gap response (no citation expander) |
| Rate limit (429) | Input re-enabled after retry; amber warning inline above input "Permintaan ditunda — mencoba kembali..." |

**Source for spinner labels:** REQUIREMENTS.md RETR-04, RETR-05, RETR-06; `app/main.py` existing spinner "Mencari referensi..."

### Query Type Badge

Renders below the assistant response header, before the prose body. Badge is inline, not a separate container.

|------------|-----------|-------|
| Calculation | "Kalkulasi" | 12px, Inter, accent-blue-06 fill, accent-blue-25 border, radius-sm |
| Simple | no badge | hidden — simple queries do not display a badge (default path) |
| Medium | "Analisis" | 12px, Inter, `rgba(148,163,184,0.12)` fill, `rgba(148,163,184,0.25)` border |
| Complex | "Mendalam" | 12px, Inter, same as Medium |

**Source:** REQUIREMENTS.md RETR-05; RESEARCH.md Pattern 4

### Conversation Memory Indicator (UI-02)

In the sidebar, below the divider:

- Show: "Percakapan: N pertanyaan" where N = `len(conversation_history) // 2`
- Style: `st.caption()` — muted text, 12px, no bold
- Reset button: "Mulai ulang percakapan" — `st.button()` with no accent styling; on click: clear `st.session_state.messages`, reset `session_id` to new UUID4

**Source:** REQUIREMENTS.md UI-02; RESEARCH.md Pattern 3
