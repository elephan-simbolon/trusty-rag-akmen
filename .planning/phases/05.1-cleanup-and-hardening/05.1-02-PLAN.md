<objective>
Close FLAG-3 from audit v1.0: all 6 frontend call sites that use raw `import.meta.env.VITE_API_BASE_URL` are replaced with a centralized `API_BASE_URL` constant imported from `frontend/src/lib/api.ts`. Also gate the `main.tsx` startup warning to dev-only, and document SC-4 (Streamlit removal) as pre-satisfied.

Purpose: In a production build (`vite build`), Vite substitutes absent `VITE_*` variables with `undefined`. Without a fallback, every API call resolves to `undefined/api/query` — a broken URL. The correct production setup uses relative URLs (empty-string base), which work because FastAPI serves the SPA from the same origin. Centralizing the fallback in one module (`api.ts`) makes it DRY, TypeScript-typed, and consistent across all 6 call sites.

Output: `frontend/src/lib/api.ts` (new file) + 6 updated frontend files with no raw `import.meta.env.VITE_API_BASE_URL` references. TypeScript compiles cleanly. Vite builds without errors.

SC-4 note: `app/` directory and `streamlit` pyproject.toml dependency were already removed before this audit. This plan documents the pre-satisfied status — no deletion tasks needed.
