    **Step 3: Verify dry-run metadata in Qdrant**

    Run this verification script to check chunk count and spot-check metadata:

    ```bash
    uv run python -c "
    from qdrant_client import QdrantClient
    from qdrant_client.models import FieldCondition, Filter, MatchValue
    from config.settings import settings

    api_key = settings.qdrant_api_key
    if hasattr(api_key, 'get_secret_value'):
        api_key = api_key.get_secret_value()

    client = QdrantClient(url=settings.qdrant_url, api_key=api_key)

    count = client.count(
        collection_name=settings.qdrant_collection_name,
        count_filter=Filter(must=[FieldCondition(key='source_domain', match=MatchValue(value='consulting'))]),
        exact=True,
    ).count
    print(f'Consulting chunks in Qdrant: {count}')

    results, _ = client.scroll(
        collection_name=settings.qdrant_collection_name,
        scroll_filter=Filter(must=[FieldCondition(key='source_domain', match=MatchValue(value='consulting'))]),
        limit=1,
        with_payload=True,
    )
    if results:
        print('Sample payload:', results[0].payload)
    else:
        print('No consulting points found — check ingestion logs')
    "
    ```

    **Expected results:**
    - `Consulting chunks in Qdrant` > 0 (expected ~130-600 per book = ~390-1800 for 3 books)
    - Sample payload includes: book_title, chapter, page_start, page_end, author (non-empty), source_domain="consulting"
    - No ERROR lines in ingestion output

    If any required metadata field is missing or author is empty, stop and report — do not proceed to full ingestion.

    **Step 4: If dry-run validated, ingest remaining 18 books**

        --source-domain consulting \
        --book-title "FULL BOOK TITLE" \

        --no-vlm

    Use individual commands — do NOT use directory batch mode (scripts/ingest.py data/pdfs/consulting/) because that sets a single --author for all books, and consulting books have different authors.

    If any book ingestion fails mid-batch, the pipeline has checkpoint resume — re-run the same command and it resumes embedding from where it left off.

    **Step 5: Final Qdrant count verification**

    ```bash
    uv run python -c "
    from qdrant_client import QdrantClient
    from qdrant_client.models import FieldCondition, Filter, MatchValue
    from config.settings import settings

    api_key = settings.qdrant_api_key

        api_key = api_key.get_secret_value()

    count = client.count(
        collection_name=settings.qdrant_collection_name,
        count_filter=Filter(must=[FieldCondition(key='source_domain', match=MatchValue(value='consulting'))]),
        exact=True,
    ).count
    print(f'Total consulting chunks: {count}')
    total = client.count(collection_name=settings.qdrant_collection_name, exact=True).count
    print(f'Total all chunks: {total}')
    "
    ```

    Expected total consulting chunks: 2,800-12,600 (wide range due to book length variance).
