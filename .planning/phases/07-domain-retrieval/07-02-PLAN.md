<objective>
Add the domain_filter parameter to hybrid_search and thread source_domain from the CLI flag through the ingestion pipeline into chunk metadata, completing the infrastructure layer for domain-aware retrieval and tagging.

Purpose: RETR-01 requires hybrid_search to optionally filter by source_domain via Prefetch.filter on both the dense and sparse Prefetch objects. RETR-04 requires the ingestion pipeline to accept a domain tag at the CLI level and stamp it on every chunk so upload_batch carries it to Qdrant automatically. Both changes default to "accounting" / None — no existing behavior changes.

Output: Extended vector_search.py (domain_filter param + source_domain in returned metadata), extended pipeline.py (source_domain param stamped on chunks), extended ingest.py (--source-domain flag).
</objective>

    Args:
